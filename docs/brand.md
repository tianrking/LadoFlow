# LadoFlow brand guide

## Name

`LadoFlow` is written as one word with a capital `L` and `F`.

- **Lado**: Spanish for side/beside.
- **Flow**: smooth movement and an uninterrupted working rhythm.
- Intended pronunciation: `LAH-doh-flow`; natural regional variation is acceptable.

Preferred product description:

> Turn the screen beside you into a smooth, private second display.

Spanish:

> Convierte la pantalla que tienes al lado en un segundo monitor fluido y privado.

## Mark

The initial mark was created specifically for this repository with OpenAI image generation and locally post-processed into transparent PNG assets. It does not incorporate third-party logos.

The geometry represents:

- a larger host display;
- a smaller mobile display placed beside it;
- a continuous cyan path that suggests the letter `L`, local transport, and frame flow;
- a coral endpoint indicating an active display connection.
