# Security Policy

## Supported versions

LadoFlow is pre-alpha and has no supported release yet. Security fixes will target the active development branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when available. Do not open a public issue for pairing bypasses, unauthenticated network access, memory-safety bugs, signing-key exposure, or content-capture leaks.

Include:

- the affected commit or version;
- host and display platforms;
- connection type;
- reproduction steps or a minimal proof of concept;
- the expected security boundary and observed behavior.

LadoFlow will not require access to unrelated personal files, credentials, or cloud accounts to reproduce a report.
