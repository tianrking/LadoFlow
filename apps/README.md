# Applications

This directory will contain user-facing applications:

- `desktop/` — Tauri-based shell shared across Windows, macOS, and Linux, with native platform services behind it;
- `android/` — native Kotlin application using Android hardware decoding and USB APIs;
- `apple/` — native Swift/SwiftUI application for iOS and iPadOS.

These directories will be created only when each scaffold has a reproducible local build.
